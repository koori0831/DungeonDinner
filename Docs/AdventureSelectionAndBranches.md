# 도구 획득 빈도와 단계형 이벤트

## 이벤트 추첨

`AdventureManager`에서 다음 값을 조절한다.

| Inspector 필드 | 기본값 | 의미 |
| --- | --- | --- |
| Supply Event Chance | 0.35 | 일반·획득 후보가 모두 있을 때 획득 후보군을 뽑는 기본 확률 |
| Max Events Without Supply | 3 | 획득 기회 없이 이 횟수만큼 진행하면 다음에 획득 후보군 우선 |
| Missing Tool Weight | 2 | 획득 후보군 안에서 미보유 도구를 주는 이벤트의 상대 가중치 |

도구가 하나도 없으면 선택 가능한 획득 이벤트를 우선한다. 직전 이벤트는 후보가 여럿일 때 제외한다. 도구·재료 조건을 충족하지 못하는 선택지는 획득 기회로 세지 않는다. 획득 후보가 없는 경우에는 일반 이벤트를 진행한다. 빈 목록은 경고 후 모험을 종료하며, 중복 참조와 null은 추첨 전에 제거한다.

획득 여부는 기존 `AdventureItemReward` 및 대사 메서드 `AddAdventureItem`에서 자동으로 읽는다. 이벤트를 별도 목록에 중복 등록할 필요가 없다. 보정은 **획득할 기회를 제시한 횟수**를 기준으로 한다. 플레이어가 거절해도 보정 횟수는 초기화되며, 실제 전체 출현 비중은 빈손·연속 미출현 보정 때문에 기본 35%보다 높아질 수 있다.

후속 선택지의 획득 경로도 확인한다. 추첨 시점의 현재 인벤토리로 조건을 검사하므로, 앞 단계에서 아직 받지 않은 도구가 있어야 열리는 후속 획득 경로는 보수적으로 제외될 수 있다. 실제 후속 선택지의 해금은 해당 단계에서 다시 검사한다.

## 단계형 선택지 작성

각 선택지의 `followUpOptions`에 후속 선택지를 추가한다. 목록이 비어 있으면 기존처럼 종료한다. 별도 이벤트 SO나 씬 등록은 필요 없다.

진행 순서는 다음과 같다.

1. 이벤트의 시작 대사
2. 첫 선택지와 선택 비용 처리
3. 선택 결과 대사와 해당 단계 보상 처리
4. 후속 선택지가 있으면 표시, 없으면 진행/귀환 화면 표시

후속 선택지도 다시 `followUpOptions`를 가질 수 있다. 순환 참조는 만들지 않는다. 단계 보상은 다음 선택지를 표시하기 전에 지급되므로 받은 도구로 다음 선택지를 해금할 수 있다. 대사가 없는 중간 단계와 대사 없는 종료도 지원한다.

중간 단계에서는 `DeleteAllImageEvent`로 화면을 비우지 않는다. 마지막 단계에 기존 정리 메서드를 둔다. 기존 아이템 조건·비용·보상·프리팹을 그대로 사용한다. 툴팁에는 필요 아이템과 소모 수량만 쓴다.

## 적용한 이벤트

| 이벤트 | 첫 선택 후 추가 진행 |
| --- | --- |
| Find_Box | 상자를 살핀 뒤 망치 / 칼 / 그만두기 |
| Meet_AdventurerTrade | 거래 조건을 물은 뒤 칼 / 망치 / 거래 거절 |
| Meet_PitAdventurer | 구조 요청을 들은 뒤 밧줄 / 물 / 떠나기 |

세 이벤트 모두 첫 선택에서 즉시 떠날 수도 있다. 기존 결말과 보상은 유지했고, 중간 단계는 보상이 없는 상황 확인 대사다. 전체 이벤트 수는 55개, 선택지 객체는 159개, 대사·서술은 609줄이다.

`Tools/upgrade-adventure-branches.cjs`는 기존 세 이벤트의 결말을 후속 선택지로 연결하는 재실행 가능한 변환 도구다. 장비 이벤트 생성기에도 이 단계를 연결했다.

## 검증 실행

- Ctrl+Shift+F6: 전체 55개 이벤트의 159개 종료 경로, 툴팁, 순환 여부, 출현 보정·확률 검사
- Ctrl+Shift+F8: 기존 보상·재료·아이템·씬 등록 검사 8개
- 플레이 모드에서 Ctrl+Shift+F9: 45개 이벤트의 138개 종료 경로를 실제 버튼으로 진행. 세 단계형 이벤트 전 경로, 빈 결과 대사, 중간 보상에 의한 해금, 중복 클릭 및 보상 중복 방지를 포함
- `node Tools/normalize-adventure-text.cjs --check`: 문구 표준 및 텍스트 태그 검사

플레이 검증은 실행 중인 테스트 세션의 인벤토리를 변경한다. 테스트 뒤 플레이 모드를 종료하면 원래 편집 상태로 돌아간다.
