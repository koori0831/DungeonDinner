# 어드벤처 이벤트 문장 작성 기준

적용 범위: `Assets/Work/Adventure/SO/Dialog`의 전체 55개 이벤트, 선택지 159개, 대사·서술 609줄. 기존 이벤트와 슬라임 변형 이벤트도 포함한다.

## 대사와 서술

- 서술은 평서형 `~다`로 쓴다. 장면의 현재 상태는 `~있다`, 이미 일어난 행동과 선택 결과는 `~했다`로 쓴다.
- 등장인물의 말과 주인공의 혼잣말은 큰따옴표로 감싼다. 노인 등의 고유 말투와 상대에 따른 존댓말은 유지한다.
- 선택지는 큰따옴표와 끝 마침표 없이 `칼로 줄기를 자른다`처럼 행동으로 쓴다.
- 보상은 선택 후 결과 대사에서 설명할 수 있다. 선택지와 툴팁에는 확정 보상을 약속하는 표현을 넣지 않는다.
- 효과음은 간결하게 쓰고, TextMesh Pro 태그는 반드시 닫는다.
- 한 분기에서 길을 떠나는 서술을 반복하지 않는다.

## 툴팁

일반 툴팁과 잠긴 상태의 툴팁은 동일한 선택 조건을 표시한다.

| 조건 | 표기 예시 |
| --- | --- |
| 제한 없음 | 필요한 아이템: 없음. |
| 도구 보유 | 필요한 아이템: 탐험 등불 1개. |
| 선택 시 도구 소모 | 필요한 아이템: 밧줄 1개. 선택 시 1개 소모됩니다. |
| 재료 소모 | 필요한 아이템: 슬라임 점액 1개. 선택 시 1개 소모됩니다. |
| 미보유 조건 | 선택 조건: 칼 미보유. |

아이템 이름과 수량은 실제 조건 데이터에서 가져온다. 교환·설치 등 명시적인 선택 비용만 소모 안내에 표시한다. 결과 대사 중 발생하는 도구 파손은 미리 밝히지 않으며, 도구가 반드시 유지된다는 문구도 쓰지 않는다.

## 적용과 검증

`node Tools/normalize-adventure-text.cjs`로 문장을 정리하고 `node Tools/normalize-adventure-text.cjs --check`로 전체 검증을 실행한다. 기존 11개 이벤트의 교정 대사는 `Tools/adventure-text-revisions.json`에 보관한다. 두 장비 이벤트 생성기도 저장 후 동일한 규칙을 적용한다.

이번 변경에서 모든 이벤트의 텍스트 필드를 제외한 직렬화 내용이 변경 전과 동일함을 검사했다. 선택 조건·수량, 보상, 메서드, 참조 ID, 이미지 및 대사 실행 순서는 유지했다. 55개 이벤트의 선택지/툴팁 수 일치, 조건 아이템 참조, 대사 따옴표와 크기 태그, 재실행 시 변경 없음 검사를 통과했다.

문구 정리 당시에는 파일 데이터 검증을 실행했다. 이후 단계형 이벤트를 추가하면서 Unity 검증도 확장했다. 현재 검증 범위와 실행 방법은 `Docs/AdventureSelectionAndBranches.md`를 참고한다.
