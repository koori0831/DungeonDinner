# DungeonDinner 프로덕션 백로그

완료되지 않은 프로덕션 작업을 실제 구현으로 오인하지 않도록 이 문서에서 추적한다.

## 게임플레이

### ADVENTURE-REWARD-001 — 모험 재료 보상 확정 지급

- 상태: 기획 결정에 따라 보류
- 현재 동작: `RandomIngredientEvent`가 획득 연출과 로그만 생성한다.
- 필요 동작: 확정된 보상마다 인벤토리 추가 요청을 보내고, 공간 부족 시 넘친 수량을 안내한다.
- 완료 조건: 모험 결과, 인벤토리, 요리 재료 수량, 저장 데이터가 모두 같은 수량을 표시한다.

### ECONOMY-BILLING-001 — 파견 비용과 정기 청구서

- 상태: 기획 예정, 지갑 차감 API 준비 완료
- 파견: 플레이어가 확인한 뒤 명시된 비용을 한 번만 차감한다.
- 유지비: 설정된 게임 시간 주기마다 청구서를 만들고 준비 UI에 다음 납부 시점을 표시한다.
- 실패: 필수 청구서를 납부하지 못하면 전용 게임오버 이벤트를 발생시킨다. 활성화 전 재도전 및 초기화 정책을 확정해야 한다.
- 완료 조건: 모든 차감 내역에 사유, 금액, 납부 시점, 확인 정책, 저장된 거래 결과가 존재한다.

## UI와 에셋

- 요리 미니게임의 `TemporaryLabel` 도구 그래픽을 시안 승인 후 에셋별로 교체한다.
- 임시 합성 효과음과 비어 있는 결과 효과음을 승인된 오디오로 교체한다.
- 오딘, 나리, 보람, 룩 초상화를 제작하고 공용 이미지는 폴백으로만 사용한다.
- 이끼동굴과 화산지대 파견 일러스트를 제작한다.
- 사진풍 `TempBackGround`와 무료 아이콘 팩 참조를 공용 빈티지 요리책 스타일로 교체한다.
- `GrindingIcon.png`을 실제 알파가 있는 PNG로 다시 내보내고 모든 요리 아이콘을 64–128px에서 검수한다.
- Game View 비교 검수 후 uGUI와 UI Toolkit의 색상, 글자 단계, 패널 스킨, 버튼 크기를 통합한다.
- 1280×720, 1920×1080, 2560×1440, 3440×1440, 4:3 화면과 키보드/게임패드 포커스를 검증한다.
