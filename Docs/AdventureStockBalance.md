# 보유량에 따른 획득 빈도와 도구 사용 이벤트

2026-09-09 변경. 보유량은 어드벤처 도구의 **중복 포함 총수량**이다. 요리 재료 수량은 포함하지 않는다. 예를 들어 칼 3개와 밧줄 2개는 도구 5개로 계산한다.

| 도구 보유량 | 획득 후보군 기본 확률 |
| --- | --- |
| 0개 | 선택 가능한 획득 후보 우선 |
| 1개 | 24.5% |
| 2개 | 15.75% |
| 3개 | 9.8% |
| 4개 | 6.3% |
| 5개 | 4.2% |
| 6개 이상 | 2.45% |

표는 `Supply Event Chance = 0.35` 기준이다. Inspector의 기준값에 수량별 계수를 곱한다. 1개 보유 중에는 기본 설정상 일반 이벤트 6회 후 획득 기회를 제공하지만, 2개 이상부터 강제 획득 보정을 해제한다. 소모로 보유량이 줄면 다음 추첨부터 즉시 새 확률이 적용된다.

일반 후보군에서는 도구를 2개 이상 보유한 경우 현재 실행 가능한 도구 사용 이벤트에 가중치 2를 준다. 4개 이상이면 도구 소모 선택지가 있는 이벤트에는 가중치 3을 준다. 필요한 도구가 없거나 도구 미보유를 요구하는 선택지는 사용 가중치를 받지 않는다. 이벤트 하나에 여러 사용 선택지가 있어도 가중치를 중복 합산하지 않는다.

직전 이벤트 제외, 미보유 도구 우대, 재료 부족 거래 제외는 유지한다. 후보군이 하나뿐이면 해당 후보군으로 진행하므로 위 수치는 매번의 무조건적인 출현 확률은 아니다.

## 추가 이벤트 12개

| 이벤트 | 사용 도구 | 소모 선택지 |
| --- | --- | --- |
| 야영지 말뚝 작업 | 칼 / 망치 | 칼을 건넴 |
| 밀랍으로 봉한 소금 항아리 | 칼 / 망치 | 없음 |
| 끊어진 다리 난간 | 밧줄 / 등불 | 밧줄 설치 |
| 밤길의 채집꾼 | 등불 / 밧줄 | 등불을 건넴 |
| 절임 요리사의 용기 | 채집병 / 집게 | 채집병을 건넴 |
| 거품이 솟는 바위 틈 | 집게 / 채집병 | 없음 |
| 뿌리에 걸린 짐 | 밧줄 / 칼 | 밧줄로 재포장 |
| 돌 화덕 수리 | 망치 / 집게 | 망치를 건넴 |
| 동굴의 부상자 | 등불 / 채집병 | 등불을 남김 |
| 수액에 붙은 콘치즈 | 칼 / 채집병 | 없음 |
| 울림이 들리는 벽장 | 망치 / 등불 | 없음 |
| 게 우리 손보기 | 집게 / 밧줄 | 집게를 건넴 |

각 도구의 사용 선택지 4개씩, 총 24개 사용 선택지와 12개 떠나기 선택지를 추가했다. 8개 선택지가 도구 1개를 소모한다. 보상은 기존 요리 재료이며 새 도구를 지급하지 않는다. 기존 이미지와 프리팹을 재사용한다. 툴팁은 필요 아이템과 소모 수량만 안내한다.

현재 전체 규모는 이벤트 67개, 선택지 객체 195개, 서술·대사 705줄이다. 두 기존 테스트 씬의 이벤트 목록에 등록했다.

새 콘텐츠 원본: `Tools/adventure-stock-encounters.cjs`.
생성 명령: `node Tools/generate-adventure-encounters.cjs ./adventure-stock-encounters.cjs`.
기존 24개 이벤트 원본은 재생성하지 않는다.

검증은 Ctrl+Shift+F6의 보유량별 확률·강제 획득 해제·사용 가중치·전체 데이터 검사, Ctrl+Shift+F8의 보상·등록 검사, 플레이 모드의 Ctrl+Shift+F9 실제 UI 경로 검사를 사용한다.
