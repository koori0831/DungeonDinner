## 소모와 보상

대부분 도구는 회수한다. 길 잃은 머쉬룸맨의 통행용 밧줄, 기운 수레의 지지용 밧줄, 노인의 주머니를 묶는 밧줄, 화분 지지용 밧줄은 현장에 남겨 1개 소모한다. 가시가 박힌 머쉬룸맨에게 건네는 채집병도 1개 소모한다. 보상은 기존 식재료 1~3개이며 구체적인 보상은 결과 대사와 획득 시점에 알려 준다. 새 획득·소모 상태나 지속 퀘스트는 추가하지 않았다.

## 연결과 유지보수

에셋은 Assets/Work/Adventure/SO/Dialog 아래에 있다. AdventureTestScene과 CookTestScene에 각각 중복 없이 등록했다. 열린 씬에는 Ctrl+Shift+F7로 이벤트 목록만 병합한다. 다른 씬 수정은 저장하거나 덮어쓰지 않는다.

원고는 Tools/adventure-equipment-encounters.cjs, 생성 도구는 Tools/generate-adventure-encounters.cjs다. 프로젝트 루트에서 Node로 실행하며 이번 24개 에셋만 작성하고 기존 GUID를 유지한다. Inspector 수정 후 재생성하려면 원고에도 반영해야 한다.

## 검증

파일 검사에서 이벤트 24개, 선택지 72개, 도구별 사용 12개, 조건 없는 떠나기, 보상 범위, 이미지 프리팹, managed reference와 두 씬의 단일 등록을 확인했다. Unity 에디터/플레이 검사는 기존 추가분까지 44개 이벤트·132개 선택지로 확장했다. Ctrl+Shift+F8은 에디터 검사, Ctrl+Shift+F9는 AdventureTestScene 플레이 검사다.

2026-09-08 Unity 6000.3.13f1에서 에디터 검사 8개와 실제 UI 선택지 132개 모두 통과했다. 도구 부족 시 잠금, 도구·재료 소모, 인벤토리 보상, 중복 클릭, 장비 아이콘 수량, 이미지 정리와 선택지 글자 경계를 검증했다. 1920×1080 Game View 캡처를 확인했으며, 실행 중 런타임 오류·누락 글자·삭제된 트윈 대상 경고는 없었다. 별도 실행 파일 빌드는 수행하지 않았다. 결과 원문은 Docs/AdventureMoreEncountersEditValidation.txt와 Docs/AdventureMoreEncountersPlayValidation.txt에 보관했다.
