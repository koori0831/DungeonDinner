# 파견 & 모험 재료 획득 시스템 기획서 초안

## 1. 문서 목적

이 문서는 `DungeonDinner`의 요리 재료 획득 콘텐츠인 `파견`과 `모험`의 기획 방향을 정리하기 위한 초안이다.

현재 게임의 핵심 플레이는 손님에게 요리를 만들어 대접하는 것이다. 플레이어는 손님의 주문과 반응을 바탕으로 보유한 재료를 사용해 요리를 만들고, 영업이 끝난 뒤 다음 영업을 준비하기 위해 재료를 수급한다.

재료 획득 콘텐츠는 손님이 온 직후 부족한 재료를 즉석에서 구하러 가는 시스템이 아니다. 하루 영업이 끝난 뒤 남는 시간에 진행하는 준비 단계이며, 플레이어는 다음 손님이 정확히 무엇을 원할지 모르는 상태에서 재료 풀을 넓히고 부족한 재료군을 보충한다.

## 2. 핵심 요약

재료 획득 방식은 크게 두 가지다.

| 구분 | 설명 |
| --- | --- |
| 파견 | NPC를 특정 지역으로 보내고, N일차가 지난 뒤 복귀한 NPC가 재료를 가져오는 장기 수급 방식 |
| 모험 | 플레이어가 직접 지역을 진행하며 이벤트를 만나고, 선택지에 따라 재료와 상황이 달라지는 즉시 수급 방식 |

파견은 안정적인 장기 운영 판단을 담당한다. 모험은 영업 종료 후 바로 진행할 수 있는 선택지 기반 탐험 콘텐츠를 담당한다.

두 시스템의 공통 목표는 다음과 같다.

- 다음 영업을 위한 재료 비축
- 부족한 재료군 보충
- 새로운 레시피 실험 가능성 확보
- 희귀 재료와 특수 재료 발견
- 지역별 재료 특징 학습
- 도감, 손질법, 요리 지식 확장

## 3. 전체 게임 루프 안에서의 위치

파견과 모험은 영업 전이나 손님 응대 중에 끼어드는 시스템이 아니라, 하루 영업이 끝난 뒤 발생하는 준비 단계다.

기본 루프는 다음과 같다.

```text
영업 시작
-> 손님 방문
-> 보유 재료와 요리 지식으로 요리 제작
-> 손님에게 요리 대접
-> 반응, 보상, 지식 갱신
-> 하루 영업 종료
-> 남는 시간에 파견 지시 또는 모험 진행
-> 재료 획득 및 인벤토리 반영
-> 다음 영업 준비
```

중요한 전제는 `다음 손님이 무엇을 좋아할지 정확히 알 수 없다`는 점이다. 따라서 재료 획득의 목적은 특정 손님 하나를 저격하는 것이 아니라, 불확실한 다음 영업에 대비해 선택지를 늘리는 것이다.

## 4. 디자인 원칙

### 4.1 재료 수급은 준비 단계다

플레이어는 손님이 온 뒤 필요한 재료를 즉시 구하러 가지 않는다. 현재 보유한 재료 안에서 최선의 요리를 만들고, 영업이 끝난 뒤 부족했던 재료나 앞으로 필요할 것 같은 재료를 수급한다.

### 4.2 플레이어는 완전한 미래 정보를 갖지 않는다

다음 손님, 다음 주문, 다음 취향을 정확히 알 수 없기 때문에 플레이어는 예측과 대비를 해야 한다. 이 불확실성이 재료 수급의 전략성을 만든다.

### 4.3 파견은 운영 판단, 모험은 선택 판단이다

파견은 `어느 NPC를 어느 지역에 며칠 동안 보낼 것인가`가 핵심이다. 모험은 `지금 마주친 이벤트에서 어떤 선택을 할 것인가`가 핵심이다.

### 4.4 재료는 단순 보상이 아니라 요리 가능성이다

재료는 인벤토리에 쌓이는 숫자 이상의 의미를 가진다. 재료의 종류, 태그, 위험성, 손질 가능성은 레시피 발견과 손님 반응에 영향을 준다.

## 5. 주요 용어

| 용어 | 의미 |
| --- | --- |
| 영업일 | 손님을 받고 요리를 제공하는 하루 단위 |
| 영업 종료 | 손님 응대가 끝나고 재료 수급, 정산, 준비를 하는 시점 |
| 재료군 | 버섯, 고기, 점액, 향신료, 광물, 채소 등 비슷한 성격의 재료 묶음 |
| 지역 | 파견 또는 모험을 보낼 수 있는 장소 |
| 위험도 | 실패, 피해, 보상 손실, 강제 전투 등 부정 결과가 발생할 가능성 |
| 희귀 재료 | 낮은 확률 또는 위험 선택을 통해 얻는 특수 재료 |
| 파견 일수 | NPC가 파견 후 복귀하기까지 필요한 영업일 수 |
| 모험 진행도 | 모험 중 길을 얼마나 나아갔는지 나타내는 값 |
| 이벤트 | 모험 중 발생하는 상황 단위 |
| 선택지 | 이벤트에서 플레이어가 고르는 행동 |

## 6. 파견 시스템

### 6.1 개요

파견은 NPC를 특정 지역으로 보내 재료를 얻는 장기 수급 시스템이다. 플레이어는 영업 종료 후 파견할 지역과 NPC를 선택한다. 파견된 NPC는 즉시 보상을 가져오지 않고, 지정된 일수가 지난 뒤 복귀한다.

파견의 목적은 안정적인 재료 공급망을 만드는 것이다. 플레이어는 오늘 당장 쓸 재료가 아니라, 며칠 뒤 영업에 도움이 될 재료를 예상하고 준비한다.

### 6.2 기본 흐름

```text
영업 종료
-> 파견 화면 진입
-> 파견 가능 지역 확인
-> 지역 선택
-> 파견할 NPC 선택
-> 예상 소요 일수, 주요 보상, 위험도 확인
-> 파견 시작
-> 날짜 진행
-> NPC 복귀
-> 파견 결과 확인
-> 재료 획득
```

### 6.3 플레이어의 주요 판단

파견에서 플레이어가 고민해야 하는 요소는 다음과 같다.

- 지금 부족한 재료군은 무엇인가
- 며칠 뒤 필요할 가능성이 높은 재료군은 무엇인가
- 어느 지역이 해당 재료군을 잘 제공하는가
- 어떤 NPC가 해당 지역에 잘 맞는가
- NPC를 며칠 동안 사용할 수 없어도 괜찮은가
- 위험도가 높은 지역에 보낼 가치가 있는가

### 6.4 파견 지역 예시

| 지역 | 소요 일수 | 주요 재료 | 위험도 | 특징 |
| --- | ---: | --- | ---: | --- |
| 근처 숲 | 1일 | 버섯, 허브, 열매 | 낮음 | 기본 재료를 안정적으로 수급 |
| 축축한 동굴 | 2일 | 점액, 광물염, 희귀 버섯 | 중간 | 특수 조리 재료가 등장 |
| 폐허 지하 | 3일 | 마물 부산물, 오래된 향신료 | 높음 | 희귀 재료 가능성이 높음 |
| 얼어붙은 길 | 2일 | 얼음 결정, 냉기 식물 | 중간 | 보존, 냉각 계열 재료 수급 |

### 6.5 파견 결과 구조

파견 결과는 완전 고정 보상보다 `예상 가능한 보상 + 변동 보상` 형태가 좋다.

| 결과 요소 | 설명 |
| --- | --- |
| 기본 보상 | 지역에 따라 높은 확률 또는 확정으로 얻는 재료 |
| 추가 보상 | NPC 특성, 지역 숙련도, 운에 따라 얻는 추가 재료 |
| 희귀 보상 | 낮은 확률로 얻는 특수 재료 |
| 부분 성공 | 복귀는 했지만 보상량이 적거나 희귀 보상을 얻지 못함 |
| 실패 | 보상이 없거나 매우 적음 |
| 부가 발견 | 새 지역 소문, 재료 정보, 레시피 힌트 등을 획득 |

### 6.6 NPC와 파견의 관계

NPC마다 파견에 영향을 주는 특성을 가질 수 있다.

예시 특성:

- 숲 지역 보상 증가
- 동굴 위험도 감소
- 희귀 재료 발견 확률 증가
- 파견 소요 일수 감소
- 실패해도 최소 보상 보장
- 특정 재료군 획득량 증가

NPC 특성은 파견 지역 선택을 단순 확률 선택이 아니라 조합 선택으로 만든다.

### 6.7 파견 상태

파견은 다음 상태를 가진다.

| 상태 | 설명 |
| --- | --- |
| 대기 중 | NPC가 파견 가능 |
| 파견 중 | NPC가 특정 지역에 나가 있음 |
| 복귀 가능 | 소요 일수가 지나 결과를 받을 수 있음 |
| 복귀 완료 | 결과를 확인하고 보상을 받은 상태 |

### 6.8 파견 UI 요구사항

파견 화면에는 다음 정보가 필요하다.

- 파견 가능 지역 목록
- 지역별 예상 재료군
- 예상 소요 일수
- 위험도
- 희귀 보상 가능성
- 파견할 NPC 선택
- NPC별 보너스 표시
- 현재 파견 중인 NPC 목록
- 복귀 예정일
- 복귀 결과 확인 화면

## 7. 모험 시스템

### 7.1 개요

모험은 플레이어가 직접 지역을 진행하며 재료를 얻는 능동 수급 시스템이다. 방향성은 `드래곤 빌리지 2`의 모험처럼, 길을 따라 진행하다가 이벤트를 만나고 선택지에 따라 다른 상황이 연출되는 방식이다.

모험은 파견보다 즉각적인 보상을 제공한다. 대신 선택에 따라 위험도가 오르거나, 피해를 입거나, 원하지 않는 이벤트로 이어질 수 있다.

### 7.2 기본 흐름

```text
영업 종료
-> 모험 지역 선택
-> 탐험 시작
-> 길 진행
-> 이벤트 발생
-> 선택지 선택
-> 결과 연출
-> 재료 획득, 위험 증가, 전투 발생, 추가 이벤트 연결
-> 계속 진행 또는 귀환 선택
-> 최종 정산
```

### 7.3 모험의 플레이 감각

모험은 자유롭게 맵을 돌아다니는 구조보다, 단계별 진행과 이벤트 선택을 중심으로 한다. 플레이어는 길을 나아가며 상황을 만나고, 그때마다 선택지를 통해 결과를 만든다.

핵심 재미는 다음과 같다.

- 안전한 선택과 위험한 선택 사이의 고민
- 같은 이벤트라도 선택에 따라 다른 보상 획득
- 연속된 선택으로 만들어지는 모험 흐름
- 위험을 감수하고 희귀 재료를 노리는 판단
- 모험 중 언제 귀환할지 정하는 판단

### 7.4 이벤트 기본 구조

모험 이벤트는 다음 정보를 가진다.

| 항목 | 설명 |
| --- | --- |
| 이벤트 이름 | 플레이어에게 표시되는 상황 이름 |
| 상황 설명 | 현재 어떤 일이 일어났는지 설명 |
| 선택지 목록 | 플레이어가 고를 수 있는 행동 |
| 선택 결과 | 선택 후 발생하는 결과 |
| 보상 | 획득 재료, 정보, 도구 등 |
| 위험 변화 | 위험도, 피해, 상태 이상 등 |
| 후속 이벤트 | 특정 결과 후 이어질 수 있는 다음 이벤트 |
| 조건부 분기 | 도구, 지식, 이전 선택에 따라 달라지는 결과 |

### 7.5 선택지 결과 유형

선택지 결과는 단순 성공/실패만으로 구성하지 않는다.

| 결과 유형 | 설명 |
| --- | --- |
| 확정 결과 | 선택하면 반드시 발생 |
| 확률 결과 | 성공, 실패, 대성공, 대실패 등으로 갈림 |
| 조건부 결과 | 특정 도구, 지식, NPC 도움, 이전 선택에 따라 변화 |
| 연쇄 결과 | 다음 이벤트가 변경되거나 강제 연결 |
| 누적 결과 | 위험도, 피로도, 마물 출현률 등이 누적 변화 |
| 숨겨진 결과 | 즉시 보이지 않지만 이후 이벤트에 영향 |

### 7.6 이벤트 예시

| 이벤트 | 선택지 | 결과 |
| --- | --- | --- |
| 수상한 버섯 군락 | 조심히 채집한다 | 일반 버섯 획득, 위험 없음 |
| 수상한 버섯 군락 | 깊숙이 파본다 | 희귀 버섯 가능, 독성 포자 위험 |
| 수상한 버섯 군락 | 지나간다 | 보상 없음, 안전하게 진행 |
| 마물의 흔적 | 추적한다 | 전투 또는 둥지 발견 |
| 마물의 흔적 | 우회한다 | 위험 감소, 보상 없음 |
| 마물의 흔적 | 덫을 설치한다 | 성공 시 부산물 획득, 실패 시 위험 증가 |
| 빛나는 점액 웅덩이 | 병에 담는다 | 점액 재료 획득 |
| 빛나는 점액 웅덩이 | 농축해본다 | 고급 점액 가능, 실패 시 재료 손상 |
| 빛나는 점액 웅덩이 | 건드리지 않는다 | 안전하게 진행 |

### 7.7 전투 이벤트

모험 중 마물을 만나면 단순히 이기고 지는 전투보다, `어떤 방식으로 상대해서 어떤 재료를 얻을 것인가`가 중요하다.

마물 조우 시 선택지는 공격 방식 또는 대응 방식으로 제공된다.

| 선택 | 결과 방향 |
| --- | --- |
| 베기 | 고기, 살점류 재료 획득에 유리 |
| 찌르기 | 핵, 심장, 결정 등 정밀 부위 보존에 유리 |
| 둔기 공격 | 뼈, 껍질, 갑각류 재료 획득에 유리 |
| 포획 시도 | 위험하지만 희귀 생물 재료 획득 가능 |
| 도망 | 보상 없음, 피해 회피 |

전투 선택은 승패뿐 아니라 획득 재료의 종류와 상태에 영향을 준다.

예시:

```text
마물: 동굴 점액충

베기
-> 점액 살점 획득 확률 증가
-> 핵 손상 확률 증가

찌르기
-> 점액 핵 획득 확률 증가
-> 실패 시 반격 위험

둔기 공격
-> 단단한 껍질 획득 가능
-> 점액류 보상 감소

포획
-> 살아있는 점액 재료 획득 가능
-> 실패 시 큰 피해

도망
-> 보상 없음
-> 위험도 일부 감소
```

### 7.8 모험 중 귀환

모험은 무조건 끝까지 진행해야 하는 구조보다, 중간에 귀환을 선택할 수 있는 구조가 좋다. 계속 진행하면 더 좋은 보상을 얻을 수 있지만, 위험도도 함께 증가한다.

귀환 판단 요소:

- 이미 얻은 재료를 안전하게 가져갈 것인가
- 희귀 이벤트를 더 노릴 것인가
- 현재 위험도가 감당 가능한가
- 체력, 피로도, 도구가 충분한가

### 7.9 모험 보상 정산

모험에서 얻은 재료는 탐험 중 임시 보상 목록에 쌓이고, 귀환 또는 모험 종료 시 최종 정산된다.

정산 시 처리할 수 있는 항목:

- 획득 재료 목록
- 획득 수량
- 희귀 재료 표시
- 새로 발견한 재료 표시
- 도감 갱신
- 모험 중 발생한 특수 기록
- 다음 지역 해금 여부

### 7.10 모험 UI 요구사항

모험 화면에는 다음 정보가 필요하다.

- 현재 모험 지역
- 현재 진행도
- 현재 이벤트 이름
- 상황 설명
- 선택지 버튼
- 선택 결과 연출 영역
- 획득한 임시 재료 목록
- 위험도 또는 피로도
- 계속 진행 버튼
- 귀환 버튼

## 8. 파견과 모험의 차이

| 구분 | 파견 | 모험 |
| --- | --- | --- |
| 진행 시점 | 영업 종료 후 지시, 며칠 뒤 결과 수령 | 영업 종료 후 즉시 진행 |
| 주체 | NPC | 플레이어 |
| 보상 시점 | N일차 후 | 모험 종료 직후 |
| 보상 성격 | 안정적, 예측 가능 | 선택에 따라 변동 큼 |
| 위험 성격 | 간접적 | 직접적 |
| 플레이 핵심 | 지역과 NPC 조합 관리 | 이벤트 선택과 결과 확인 |
| 주요 목적 | 장기적인 재료 공급 | 단기 보충, 희귀 재료 탐색 |
| 실패 감각 | NPC가 적은 보상을 가져오거나 실패 | 플레이어가 위험 선택의 결과를 직접 경험 |

## 9. 요리 시스템과의 연결

파견과 모험에서 얻은 재료는 요리 시스템의 기반이 된다.

연결 지점은 다음과 같다.

- 인벤토리에 재료 추가
- 요리 재료 선택 화면에서 사용 가능
- 새 재료 발견 시 도감 갱신
- 특정 재료군 확보로 레시피 실험 가능
- 손질법과 조합해 요리 결과 변화
- 희귀 재료 또는 위험 재료로 특수 요리 가능

주의할 점은 재료 수급이 `다음 손님 하나를 맞추기 위한 즉시 대응`이 아니라는 것이다. 파견과 모험은 플레이어가 앞으로의 영업에 대비해 선택지를 넓히는 준비 콘텐츠다.

## 11. 프로토타입 범위 제안

처음부터 모든 변수를 구현하기보다, 아래 범위로 작게 검증하는 것을 권장한다.

### 11.1 파견 1차 범위

- 파견 지역 3개
- 파견 가능 NPC 2명
- 지역별 기본 보상/희귀 보상
- 파견 일수 처리
- 복귀 결과 UI
- 인벤토리 재료 지급

### 11.2 모험 1차 범위

- 모험 지역 1개
- 이벤트 6개
- 이벤트당 선택지 2~3개
- 채집 이벤트
- 마물 조우 이벤트
- 전투 선택지 3종
- 귀환/정산 처리
- 인벤토리 재료 지급

### 11.3 1차 검증 목표

- 영업 종료 후 재료 수급으로 자연스럽게 이어지는가
- 파견과 모험의 역할 차이가 느껴지는가
- 모험 선택지가 단순 버튼 누르기가 아니라 판단처럼 느껴지는가
- 획득한 재료가 다음 영업에서 의미 있게 사용되는가

## 12. 예시 플레이 시나리오

```text
1일차 영업 종료
- 버섯류 재료가 거의 소진됨
- 점액 재료는 아직 충분함

플레이어 선택
- NPC 한 명을 근처 숲으로 1일 파견
- 직접 모험은 축축한 동굴로 진행

모험 중
- 빛나는 점액 웅덩이를 발견
- 농축 선택을 골라 고급 점액을 얻지만 위험도 증가
- 마물 흔적을 발견
- 우회하지 않고 추적해 전투 발생
- 찌르기를 선택해 점액 핵 획득
- 위험도가 높아져 귀환 선택

정산
- 고급 점액 1개
- 점액 핵 1개
- 일반 버섯 2개
- 새 재료 도감 등록

다음 영업
- 플레이어는 새로 얻은 재료를 활용해 이전보다 다양한 요리를 시도할 수 있음
```

## 13. 미정 사항

아래 항목은 추후 기획 확정이 필요하다.

- 하루에 파견과 모험을 둘 다 할 수 있는가
- 하루에 보낼 수 있는 파견 NPC 수
- 파견 중인 NPC가 영업 중 손님으로 등장할 수 있는가
- 모험 실패 시 획득 재료를 잃는가
- 모험에 체력, 피로도, 도구 내구도를 둘 것인가
- 모험 중 획득한 재료는 즉시 확정인가, 귀환해야 확정인가
- 희귀 재료의 획득 확률을 플레이어에게 얼마나 공개할 것인가
- 파견과 모험으로 도감 지식이 얼마나 해금되는가

## 14. 핵심 문장

파견과 모험은 특정 손님의 주문을 즉시 해결하기 위한 시스템이 아니다. 하루 영업이 끝난 뒤, 다음에 누가 올지 모르는 불확실한 상황에 대비해 재료 선택지를 넓히는 준비 콘텐츠다.

파견은 며칠 뒤를 바라보는 운영 판단이고, 모험은 지금 눈앞의 이벤트에서 위험과 보상을 저울질하는 선택 판단이다.
