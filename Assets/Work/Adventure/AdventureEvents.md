# 추가 어드벤처 이벤트

기존 11개 이벤트를 유지하고 아래 8개를 추가했습니다. 각 이벤트는 3개 선택지를 가지며, 선택 결과 대사가 끝난 뒤 기존 `IngredientReward`로 보상을 지급합니다.

| 이벤트 에셋 | 선택별 결과 |
| --- | --- |
| Find_HolySwordSalt | 검 뽑기: 없음 / 칼: 암염 1 / 망치: 암염 2, 성검 파손 연출 |
| Meet_MushroomBarber | 칼: 버섯 갓 1 / 망치: 납작버섯 1 / 길 안내: 없음 |
| Meet_AdventurerTrade | 칼 1 소모: 콘치즈 2 + 버섯 갓 1 / 망치 1 소모: 암염 2 + 납작버섯 1 / 거절 |
| Find_BoxSlime | 슬라임 내보내기: 점액 1 / 칼: 콘치즈 1 / 망치: 점액 2 |
| Find_SaltGoddess | 공물 받기: 콘치즈 1 / 칼: 암염 1 / 망치: 암염 3, 여신상 파손 연출 |
| Find_BrokenGoddessRepair | 점액 1 소모: 콘치즈 2 + 버섯 갓 1 / 망치: 암염 1 / 조각 모아두기: 없음 |
| Find_CoconutCrab | 망치: 코코넛 게살 2 / 칼: 코코넛 게살 1 / 지나가기 |
| Meet_SproutSlime | 따라가기: 콘치즈 2 / 주먹 공격: 점액 1 / 구경하기: 없음 |

- 거래를 제외한 도구 선택은 칼·망치를 유지합니다. 선택지 툴팁은 행동 설명과 필요한 도구·재료 및 소모 여부만 안내하며, 보상이나 결과를 미리 알려주지 않습니다.
- 여신상 수리는 인벤토리에 점액이 있을 때만 선택할 수 있고, 클릭 시 수량을 다시 확인한 뒤 1개를 소모합니다.
- 여신상 파괴와 수리는 각각 독립적인 무작위 만남입니다. 이전 만남을 기억하는 퀘스트/지역 상태 시스템은 추가하지 않았습니다.
- AdventureTestScene은 기존 11개와 추가 8개, CookTestScene은 기존 2개와 추가 8개가 이벤트 목록에 등록되어 있습니다.
- 코코넛 게살은 기존 아이템 카탈로그와 요리 재료 데이터에 등록했습니다. 기존 게살 이미지를 아이콘으로 사용하며, 그대로 사용·굽기·데치기를 지원합니다. 전용 3D 모델이나 새 레시피는 추가하지 않았습니다.
- CoconutCrab, CoconutCrabMeat, HurbSlime 이미지용 프리팹 3개를 기존 UI Image 프리팹에서 구성했습니다.
- 기존 나무 상자의 무작위 재료 이벤트에도 인벤토리 지급 요청을 추가했습니다.

## 검증

플레이 모드를 종료한 상태에서 `Tools > Dungeon Dinner > Adventure > Validate Added Events`로 에셋 참조, 씬 등록, 거래 보상, 점액 소모, 무작위 보상 지급, 게살 등록을 검증할 수 있습니다. 동일 검증을 NUnit 테스트로도 제공합니다.

2026-09-07, Unity 6000.3.13f1 에디터에서 다음 검증을 완료했습니다.

- 런타임 C# 및 검증 코드 컴파일, 8개 이벤트의 24개 선택지·21개 보상 항목·36개 이미지 참조와 두 씬 연결에 대한 파일 검사 통과.
- Unity 에디터에서 `AdventureContentTests`의 7개 검사 모두 통과.
- AdventureTestScene의 실제 플레이 모드에서 24개 선택지를 모두 실행하여 대사 진행, 인벤토리 보상, 도구·재료 소모, 재료 부족 시 잠금, 중복 클릭 방지, 이미지 표시·정리 및 계속/중지 UI 복귀 확인.
- 1920×1080 Game View에서 8개 이벤트 화면을 캡처하고 선택지 글자가 화면 밖으로 나가지 않는지 검사.
- 최종 실행 중 런타임 오류 및 DOTween의 삭제된 대상 참조 경고 0건.

검증 중 발견한 버튼 크기 애니메이션의 삭제된 대상 참조는 `SetLink`와 기존 트윈 정리로 수정했습니다. 화면 밖으로 길어지는 버섯 이발사 선택지 문구도 줄였습니다.

에디터 검사는 `Ctrl+Shift+F8`, 플레이 검사는 AdventureTestScene 실행 후 `Tools > Dungeon Dinner > Adventure > Validate All Choices In Play Mode` 또는 `Ctrl+Shift+F9`로 재실행할 수 있습니다. 플레이 검사는 테스트용 인벤토리와 대사 속도를 설정하므로 완료 후 플레이 모드를 종료하면 됩니다. 결과는 `Temp/AdventureEditModeValidation.txt`, `Temp/AdventurePlayValidation.txt`와 이벤트별 PNG로 저장됩니다. 별도 실행 파일 빌드 검증은 수행하지 않았습니다.
